# Алгоритм-бот

Скаффолд Telegram-бота на Go: состояние хранится в SQLite, бот привязывается к одной группе, отвечает на `/chat-id` и по расписанию публикует открытый опрос о дне проведения алгоритмов.

## Запуск

1. Создайте бота через [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Скопируйте `.env.example` в `.env`, задайте `TELEGRAM_BOT_TOKEN` и при желании остальные параметры. Переменные окружения нужно экспортировать перед запуском (файл `.env` сам по себе не загружается).
3. Добавьте бота в нужную группу и запустите:

```sh
go run ./cmd/bot
```

4. Если `TELEGRAM_CHAT_ID` пустой, отправьте `/chat-id` в нужной группе: бот сохранит эту группу как единственную разрешённую. Если ID задан, бот принимает команды только из этой группы.

Команда `/chat-id` возвращает ID текущей группы. Планировщик создаёт опрос с вариантами «Суббота» и «Воскресенье»; ответы не анонимны и сохраняются в SQLite. Расписание задаётся стандартным cron-выражением, по умолчанию — каждую пятницу в 12:00 по `Europe/Moscow`.

Чтобы отключить автоматические опросы, задайте `POLL_SCHEDULER_ENABLED=false`. Бот продолжит отвечать на команды и сохранять состояние.

## Переменные окружения

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `TELEGRAM_BOT_TOKEN` | — | Токен Telegram-бота (обязателен) |
| `TELEGRAM_CHAT_ID` | пусто | ID единственной группы; пустое значение включает привязку через `/chat-id` |
| `SQLITE_PATH` | `./data/bot.db` | Путь к файлу SQLite |
| `POLL_SCHEDULER_ENABLED` | `true` | Включить/выключить запланированные опросы |
| `POLL_CRON` | `0 12 * * 5` | Пятизначное cron-выражение |
| `TIMEZONE` | `Europe/Moscow` | Часовой пояс расписания |

## Структура

- `cmd/bot` — точка входа и конфигурация из окружения.
- `internal/bot` — обработка Telegram-команд, опросов и расписания.
- `internal/store` — SQLite-схема и операции с состоянием.
